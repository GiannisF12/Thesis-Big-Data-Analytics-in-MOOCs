# Big-Data-Analytics-in-MOOCs

This repository contains the code, data, and thesis document for the project titled “Big Data Analytics in MOOCs”. The project focuses on analyzing Massive Open Online Courses (MOOCs) data to extract meaningful insights using big data analytics techniques.

📄 Thesis Document

The detailed thesis report can be found in the thesis.pdf file. It encompasses the project’s background, methodology, analysis, results, and conclusions.

⸻

📊 Dataset

The analysis is based on a cleaned dataset derived from Coursera, available in the CourseraDataset-Clean.csv file. This dataset includes various attributes related to MOOCs, such as course titles, subjects, institutions, and more.

⸻

🧪 Code and Analysis

The project includes both a Python script and a Jupyter Notebook for data analysis:
	•	moocs.py: A Python script that performs data preprocessing and analysis.
	•	moocs.ipynb: A Jupyter Notebook that provides an interactive environment for data exploration and visualization.

⸻

⚙️ Setup Instructions

To run the analysis locally, follow these steps:

1.	Clone the repository:
 
```
 git clone https://github.com/GiannisF12/Thesis-Big-Data-Analytics-in-MOOCs.git
cd Thesis-Big-Data-Analytics-in-MOOCs
```
2.	Create a virtual environment (optional but recommended):
 
```
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3.	Install the required packages:
```
pip install pandas matplotlib seaborn
```

4.	Run the analysis:

•	To execute the Python script:
```
python moocs.py
```

 •	To launch the Jupyter Notebook:
```
jupyter notebook moocs.ipynb
```



📈 Features and Analysis

The analysis covers various aspects of MOOCs data, including:
	•	Distribution of courses across different subjects and institutions.
	•	Trends in course offerings over time.
	•	Insights into course popularity and enrollment figures.
	•	Visualizations to aid in understanding data patterns.
